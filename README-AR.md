# 🏦 نظام إدارة البنك (OOP) - المشروع المتكامل 🚀

[ **🇺🇸 Read this project in English** ](./README.md)

تطبيق بنكي قوي يعمل على واجهة الأوامر (Console) ومطور بلغة **C++**. يمثل هذا المشروع تطور النظام البنكي ليعتمد على معمارية **البرمجة كائنية التوجه (OOP)** الحديثة، ويتميز بتصميم نظيف، وهيكلة تركيبية قابلة للتوسع (Modular)، وحفظ البيانات في ملفات نصية، بالإضافة إلى وحدة جديدة كلياً لصرافة العملات.

---

## 🏗️ وحدات ومميزات المشروع

### 1️⃣ العمليات البنكية الأساسية وإدارة المستخدمين 👥
* 💼 **إدارة العملاء:** إنشاء، قراءة، تعديل، وحذف (CRUD)، بالإضافة إلى البحث عن عملاء البنك.
* 👨‍💼 **إدارة المستخدمين:** نظام متكامل لإدارة موظفي ومسؤولي البنك مع نظام صلاحيات دقيق.
* 💾 **تفاصيل تقنية:** وصول آمن للبيانات عبر (Setters/Getters) لتطبيق مبدأ التغليف (Encapsulation)، وتخزين دائم في ملفات `Clients.txt` و `Users.txt`.

### 2️⃣ نظام المعاملات المتقدم 💸
* 💳 **العمليات:** إيداع، سحب، وتحويل الأموال بأمان بين الحسابات.
* 📊 **التقارير:** عرض إجمالي أرصدة النظام وسجلات تفصيلية للتحويلات (**Transfer Logs**).
* 💾 **تفاصيل تقنية:** معالجة وتحقق صارم لمدخلات المستخدم لمنع الأخطاء وضمان سلامة البيانات.

### 3️⃣ نظام صرافة العملات 💱 (ميزة جديدة)
* 🌍 **الوظائف:** عرض العملات المتاحة، تحديث أسعار الصرف (مرتبطة بالدولار الأمريكي)، وحاسبة لتحويل العملات.
* 🔍 **البحث:** البحث عن العملات بكفاءة باستخدام اسم الدولة أو رمز العملة.
* 💾 **تفاصيل تقنية:** قراءة البيانات في الوقت الفعلي من ملف `Currencies.txt`.

### 4️⃣ المصادقة والأمان 🔐
* 🔑 **الوصول للنظام:** نظام تسجيل دخول آمن للمستخدمين المصرح لهم فقط.
* 📜 **المراجعة والتدقيق:** سجل شامل لتاريخ تسجيل الدخول (**Login Register History**) يتتبع أوقات الوصول وتفاصيل المستخدمين.

## 💻 هيكلة الكود وتصميم الـ OOP 🧬

### نموذج البرمجة كائنية التوجه
تمت إعادة هيكلة المشروع بالكامل من البرمجة الإجرائية إلى **البرمجة كائنية التوجه (OOP)**. ويستعرض هذا الإصدار مفاهيم متقدمة مثل:
* **الوراثة وتعدد الأشكال (Inheritance & Polymorphism):** استخدام فئات أساسية مجردة (Abstract Classes) للتعامل المرن.
* **التغليف (Encapsulation):** حماية حالة البيانات عبر دوال الـ Setters و Getters.
* **التجريد والتصميم التركيبي (Abstraction & Modular Design):** فصل كامل بين منطق العمل (Business Logic) وشاشات واجهة المستخدم (UI).

### 📁 الهيكلة الجديدة للمشروع
تمت إعادة تنظيم المشروع في هيكلة هرمية صارمة لضمان قابلية التوسع وسهولة الصيانة:
* 🧠 **`Core/`**: منطق العمل ونماذج البيانات (مثل: `clsBankClient`, `clsCurrency`, `clsUser`).
* 🖥️ **`Screens/`**: طبقات واجهة المستخدم للقوائم (مثل: `clsMainScreen`, `Client/`, `Currencies/`).
* 🛠️ **`Lib/`**: مكتبات أدوات مساعدة قابلة لإعادة الاستخدام (مثل: `clsString`, `clsInputValidate`, `clsDate`).
* 🗄️ **`Data/`**: قاعدة بيانات تعتمد على الملفات النصية لحفظ البيانات (مثل: `Currency.txt`, `TransferLog.txt`).

---

## 🛠️ أبرز النقاط التقنية ✨
* ⚙️ **مكتبة القوالب القياسية (STL):** استخدام واسع لـ `std::vector` لإدارة الذاكرة والبيانات بكفاءة.
* 🛡️ **مكتبات مخصصة:** بناء فئات مساعدة قوية مثل `clsString` للتعامل مع النصوص وتحليلها، و `clsInputValidate` لضمان صحة جميع مدخلات المستخدم.
* 🚀 **فصل نظيف لواجهة المستخدم:** واجهة موجه الأوامر (Console) مفصولة تماماً عن نماذج البيانات الأساسية مما يسهل تطويرها مستقبلاً.
